CDT – Cuotas Societarias v1.0.5

CAMBIOS DE ESTA VERSION
- Se conserva íntegramente la lógica de la v1.0.4.
- Nuevo ícono de instalación: escudo del Club Deportivo Tacural.
- Nombre de la PWA instalada: CDT – Cuotas Societarias.
- Nombre corto: Cuotas CDT.
- El encabezado interno continúa como Cobrador CDT.
- Versión actualizada a 1.0.5.

PUBLICACION
1. Reemplazar en el proyecto los archivos de este ZIP.
2. En VS Code ejecutar:
   git add .
   git commit -m "Actualizar Cobrador CDT a v1.0.5"
   git push
3. Esperar el despliegue automático de Vercel.
4. Abrir la app con Internet y aplicar la actualización si aparece el aviso.

IMPORTANTE SOBRE EL ICONO
Android puede conservar el ícono anterior si la PWA ya estaba instalada.
Si luego de actualizar sigue mostrando el ícono viejo, puede ser necesario quitar SOLO el acceso/PWA de la pantalla de inicio y volver a instalarla desde el navegador. Esto no debe confundirse con borrar los datos del navegador.
